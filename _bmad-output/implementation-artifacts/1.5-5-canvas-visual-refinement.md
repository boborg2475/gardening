# Story 1.5-5: Canvas Visual Refinement

Status: ready-for-dev

## Story

As a gardener working on the canvas,
I want the canvas to look and feel like a professional drafting surface,
So that the visual experience is pleasant and the grid/drawing elements are easy to read.

## Acceptance Criteria

1. **Given** the canvas area loads
   **When** the user views the canvas background
   **Then** the canvas has a distinct warm off-white/parchment background that differentiates it from the app chrome, and the area outside the property grid has a slightly darker/muted tone

2. **Given** the grid is visible on the canvas
   **When** the user views the grid lines
   **Then** major grid lines are rendered in a subtle earth-tone color (warm gray/tan) and minor grid lines are rendered even more subtly (lighter, thinner) — not stark black or bright colors

3. **Given** the user is drawing a property boundary
   **When** drawing points are placed on the canvas
   **Then** the drawing points are styled with the design system primary color (sage green), have a visible but not overwhelming size, and include a subtle border or shadow for clarity against the grid

4. **Given** the user is drawing a property boundary
   **When** lines connect the drawing points
   **Then** the connecting lines use the primary color with appropriate thickness and slight transparency, and a dashed preview line connects the last placed point to the cursor position

5. **Given** the property boundary is completed
   **When** the boundary polygon is displayed
   **Then** the boundary fill uses a very subtle primary tint (e.g., sage green at 5-10% opacity) and the boundary stroke uses the primary color — clearly marking the property area without overwhelming the grid

6. **Given** the canvas with all elements
   **When** the user views the overall composition
   **Then** there is clear visual layering: background (muted) < grid (subtle) < boundary (defined) < drawing points (prominent) — each layer is distinguishable without competing for attention

## Dev Notes

### Canvas Color Palette

The canvas should feel like a drafting surface — think graph paper on warm parchment, not a digital screen. Approximate color targets:

| Element | Color | Opacity | Notes |
|---------|-------|---------|-------|
| Canvas background (grid area) | `#F5F1EB` (parchment) | 1.0 | Matches app background or slightly warmer |
| Canvas background (outside grid) | `#E8E2D9` (darker parchment) | 1.0 | Frames the working area |
| Major grid lines | `#C4BDB4` (warm gray) | 0.5-0.6 | Visible but not dominant |
| Minor grid lines | `#D9D3CB` (light warm gray) | 0.25-0.35 | Barely visible, provides scale reference |
| Drawing points | `#6B7C5E` (sage green) | 1.0 | Prominent, with white border |
| Drawing lines | `#6B7C5E` (sage green) | 0.8 | Slightly transparent |
| Preview/cursor line | `#6B7C5E` (sage green) | 0.4 | Dashed, low opacity |
| Boundary fill | `#6B7C5E` (sage green) | 0.06-0.10 | Very subtle tint |
| Boundary stroke | `#6B7C5E` (sage green) | 1.0 | Clear boundary edge |

### Konva Color Application

Konva uses standard CSS color strings. For opacity, use either:
- Konva node `opacity` property (affects entire node)
- RGBA color strings (e.g., `rgba(107, 124, 94, 0.6)`)

Prefer RGBA strings for per-element opacity control, and reserve the Konva `opacity` property for interactive effects (hover, selection).

### Canvas Theme Module

The `canvas-theme.ts` module centralizes all canvas visual constants. This keeps rendering code clean and makes future theme changes easy:

```typescript
// src/lib/canvas/canvas-theme.ts
export const CANVAS_BACKGROUND = '#F5F1EB';
export const CANVAS_OUTSIDE = '#E8E2D9';
export const GRID_MAJOR = { color: 'rgba(196, 189, 180, 0.55)', width: 1 };
export const GRID_MINOR = { color: 'rgba(217, 211, 203, 0.3)', width: 0.5 };
// ... etc
```

### Relationship to Existing Grid Renderer

`src/lib/canvas/map/grid-renderer.ts` contains the grid line calculation logic. The color/style constants should be moved from inline values to the new `canvas-theme.ts` module. The renderer functions may need updated signatures to accept style parameters or import the theme constants directly.

### Performance Considerations

- Subtle visual effects (shadows on points, texture patterns) should be tested for performance impact at high zoom levels
- Grid line color changes have zero performance impact — same number of lines, different color values
- Avoid Konva filters or blur effects on frequently re-rendered elements

### What This Story Does NOT Include

- Changing grid calculation logic or grid scale options (Story 1.4)
- Adding new drawing tools (future stories)
- Zone or bed rendering (future epic)
- Animated drawing effects
- Dark mode canvas variant
